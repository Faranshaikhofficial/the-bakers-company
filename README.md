# The Bakers Company (@the_bakers_company) 🍰

A premium, responsive, mobile-first web application for **The Bakers Company** boutique seating bakery and cafe located at MCCH Society, Panvel.

## ✨ Features
- **Modern Luxury UI/UX**: Warm Deep Chocolate Brown (`#3D2314`), Sweet Cream (`#FDFBF7`), and Gold (`#D4AF37`) aesthetic.
- **Page 1: Landing Page**:
  - Sticky navigation bar with Instagram button (`@the_bakers_company`) & mobile navigation drawer.
  - Hero section showcasing handcrafted bakes and direct CTA.
  - Split About & Vibe section highlighting the cozy seating area at Moreshwar Niwas.
- **Page 2: Digital Menu & Catalog**:
  - 3 dynamic categories: *Premium Celebration Cakes*, *Fresh Pastries & Slices*, and *Special Premium Desserts*.
  - Category filter tabs with responsive grid layout.
  - Price tags and prominent **Order via WhatsApp** buttons.
- **Direct WhatsApp Ordering**:
  - Instant pre-filled order inquiry connected to official number: `+91 98339 55999`.
- **Location & Contact**:
  - Address: Shop no.1 Plot no.35, Moreshwar Niwas, MCCH Society, Panvel, Maharashtra 410206.
  - Call link: `098339 55999`.
  - Google Maps integration.
- **Floating Quick WhatsApp CTA** with pulse animation.

## 🚀 Built With

- Modern Vanilla JavaScript
